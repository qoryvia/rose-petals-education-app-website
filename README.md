# Rose Petals Convent School, Kasia (Kushinagar)

React + Vite + Tailwind CSS + React Router + React Icons.

## Run
    npm install
    npm run dev       # http://localhost:5173
    npm run build     # production build in /dist

## Edit content
All school text, phone numbers, facilities and links live in `src/data/siteData.js`.
Brand colours are in `tailwind.config.js` (crimson, navy, gold, cream, leaf), sampled from the emblem.
To add real campus photos, replace the icon panels in `src/pages/Home.jsx` with `<img>` tags.
